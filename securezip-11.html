There is no password recovery — if it's lost, the data is unrecoverable.

keyfile

A second secret, like a second factor — both the password AND this exact file are needed to decrypt. Losing either one loses the data.

Each recipient gets their own password (and optional keyfile) that unlocks the same content — good for sharing one file with a few people without sharing one password.

Advanced

Higher is slower to brute-force, but also slower to encrypt and decrypt. 250,000 is a solid default.

Add a decoy (advanced)

A second, different password will reveal separate decoy content instead of your real file — useful as basic misdirection. This is not true plausible deniability. Unlike a fixed-size hidden-volume tool, this archive's size can still hint that it holds more than one payload to someone who examines it closely. Don't rely on this alone in a high-stakes situation.

Split output into parts

Useful for email limits or unstable connections. Only kicks in if the result is bigger than the chosen size — drop every part back in on the Decrypt side to reassemble. Works whether or not you're also encrypting.
